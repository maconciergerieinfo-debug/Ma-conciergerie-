# Ma Conciergerie — Auto & Maison

## Mise en ligne
1. Importez ce dossier dans un dépôt GitHub privé.
2. Connectez le dépôt à un hébergeur Node.js.
3. Commande d'installation : `npm install`
4. Commande de démarrage : `npm start`
5. Ajoutez les variables `OWNER_EMAIL`, `OWNER_PASSWORD` et `JWT_SECRET`.

## Important
Ne mettez jamais vos mots de passe dans GitHub.
La base `data/database.json` est créée automatiquement au premier lancement.
Pour une utilisation professionnelle, utilisez un stockage persistant et des sauvegardes.
